# GlowWoodCutter

Премиальный плагин для организации профессии лесоруба на сервере Minecraft (Paper / Spigot / Purpur / Folia 1.16.5–1.21).

## Особенности

- Настройка неограниченного количества зон лесоруба с привязкой к регионам WorldGuard.
- Гибкая система наград через продвинутый Actions Engine (команды консоли, команды игрока, сообщения, титлы, звуки, партиклы, боссбары).
- Поддержка интерактивных hover- и click-элементов в чате (`[HoverText:url ...]`, `[HoverText:cmd ...]`).
- Автоматическая регенерация срубленных блоков через заданное время с сохранением исходного типа и ориентации.
- Возможность включения или отключения выпадения предметов (дропа) при рубке.
- Защита зоны от установки сторонних блоков во время восстановления.
- Поддержка PlaceholderAPI и удобное автодополнение команд.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/glowwoodcutter reload` | Перезагрузить конфигурацию плагина | `glowwoodcutter.admin` |
| `/glowwoodcutter restore` | Мгновенно восстановить все срубленные блоки | `glowwoodcutter.admin` |
| — | Право на работу лесорубом | `glowwoodcutter.cutting` |

## Зависимости

- **WorldEdit** / **FastAsyncWorldEdit**
- **WorldGuard** (v7.0+)
- **PlaceholderAPI** (опционально)
